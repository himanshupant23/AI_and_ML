## Quick start
1. Clone the repository:

   git clone https://github.com/himanshupant23/AI_and_ML.git
   cd AI_and_ML

2. Create a virtual environment (recommended):

   python3 -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   .venv\Scripts\activate     # Windows (PowerShell)

3. Install dependencies

If this repo contains a `requirements.txt` or `environment.yml`, install dependencies with one of the following:

- pip (if requirements.txt exists):

  pip install -r requirements.txt

- conda (if environment.yml exists):

  conda env create -f environment.yml
  conda activate <env-name>

4. Run Jupyter Lab or Notebook

   pip install jupyterlab   # if not installed
   jupyter lab

Open the notebooks in your browser and run cells interactively.
